# 概要
MSX2++用のAudio「Y8960」の開発用リポジトリです。
Y8960 Cartridge として開発しています。
MSX1/2/2+/turboR に装着することで利用可能です。

# Spec
- SSG (PSG) 2セット
- OPLL 1セット (MSX-MUSIC)
- OPL2 + ADPCM 1セット (MSX-AUDIO)
- SCC 1セット
- OPM 1セット

OPLL は、OPLL/OPLL-P/OPLL-X/VRC7相当 の ROM音色データを搭載しており、チャネルごとに選択可能です。
SSG/OPLL/OPL2/ADPCM/SCC はステレオ対応に拡張してあります。

# 残件
- 2個以上 Y8960 Cartridge を接続すると System Control Port がバス競合を起こすので2個以上付けちゃダメ
	→ 次の基板リビジョンで SystemControlPort をスイッチで切り離せるようにする予定
- BUSDIR が繋がっていないので、BUSDIR を見ている高級MSX2 で使えない
	→ 次の基板リビジョンで繋げる予定
- 細かいテスト

# FPGA
FPGAによるエミュレーションですので、リアルチップとは異なる音が鳴る可能性がありますが、そこのリアル性の追求は行いません。それらしい音が出たところで OK とします。
とはいえ、OPLL/OPL2/ADPCM/SCC/OPM は、再現性が高いと定評のある IP を利用させていただいています。各音源の原本の在処や、ライセンスに関しては、ソースコードの個々のフォルダに記載してありますので、そちらを参照ください。
